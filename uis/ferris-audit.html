Ferris Sweep — A+C Layout Lab

Ferris is not a small Sofle. Design the thumb OS first, then place must-haves by effort. No hold-Enter. One canonical home per action.

Sofle More keys → less modality. ~5 thumbs/side can dedicate Shift, Enter, Spc, LWR, RSE, FUNC, ADJ. Optimizes coverage. Dups are cheap.
Ferris Fewer keys → stronger modality. 2 thumbs/side = tiny OS; layers are modes of thought. Optimizes stable OS + clean modes. Empty is honest. Dups are expensive.

Principles (A+C)

  • Thumbs = OS only (layers + Spc + Enter)
  • Enter is a tap, never a hold
  • Dedicated Shift on base — HRM is bonus
  • One canonical home per glyph — dups only if intentional
  • Never delete a glyph without re-homing it
  • Raise = nav + F-keys; edit chords live on FUNC
  • ADJ/FUNC stay sparse — empty is OK
